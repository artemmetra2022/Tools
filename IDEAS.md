# ClearItems — идеи для развития

Бэклог незаконченных идей. Сделанное (артефакты CI, `/clear1 radius`,
whitelist, Жезл Магнита, прочность/кулдаун жезлов) уже в коде —
здесь только будущее.

## Геймплей

### 6. Предпросмотр зоны действия
Shift (или удержание ПКМ) показывает границу радиуса **до** клика:
- Жезл Очистки — сфера/кольцо частиц на текущем радиусе;
- Жезл Заморозки — так же, для радиуса поиска контрапшнов.
- Реализация: держать частицы только на клиенте, для этого нужен
  `IClientItemExtensions` / `onUseTick` или отрисовка в
  `Item#appendHoverText`-подобном клиентском хуке. Это самая сложная
  из идей — затрагивает клиентский код.

## Качество / инфраструктура

### 7. GameTest
Автотесты в CI: NeoForge поддерживает gametest-фреймворк
(`@GameTest`, запуск через `runGameTestServer`). Минимальный набор:
- выбросить N предметов, вызвать логику очистки, проверить счётчик;
- проверить, что whitelist-предмет не удаляется;
- проверить переключение радиуса у жезла.
Куда: `src/main/java/.../gametest/` + `runs { gameTestServer { } }`
уже почти готовы в `build.gradle` (блок `runs` из MDK-шаблона).

### 8. Локализация строк
Сейчас почти все игровые сообщения — русский текст прямо в
`Component.literal(...)`. Англоязычный игрок видит кракозябры/русский.
- Перенести все строки в `assets/clearitems/lang/en_us.json` и
  `ru_ru.json` как `key` → текст, в коде — `Component.translatable`.
- Файлы lang уже существуют (тултипы предметов там) — просто расширить.
- Заодно унифицировать сообщения команд (`/clear1`, `/clearitemshelp`).

### 9. Расширение конфига
В `ClearItemsConfig` добавить:
- `wands.default_radius_steps` — свои наборы радиусов для жезлов;
- `commands.permission_level` — уровень прав `/clear1` без пересборки;
- `welcome.message_enabled` — отключение приветствия в чате.

## Мелочи (из CI-предупреждений)

- `gradlew` без executable-бита: `git update-index --chmod=+x gradlew`
  (иначе action каждый раз пишет warning).
- actions/checkout@v4 и др. на Node 20 — обновить до @v5, когда
  станет актуально.
- Можно добавить шаг публикации GitHub Release при теге версии
  (`mod_version` из `gradle.properties` → jar в Release) — артефакты
  Actions живут 90 дней, Release — вечно.
